Morning Shortcut

When your iPhone alarm stops, a Shortcut reads last night's resting heart rate from Apple Health (your Garmin syncs it there) and hands it to Tracker's check-in. HRV doesn't sync from Garmin, so that one stays a tap.

  1. Open Shortcuts → Automation → + → Alarm → Is Stopped → Run Immediately.
  2. Add Find Health Samples: Type Resting Heart Rate, sort by Start Date, Latest First, limit 1.
  3. Add Get Details of Health Samples → Value.
  4. Add Text containing tracker:rhr= followed by the Value from step 3, then Copy to Clipboard.
  5. Add Open URLs with this link, with the Value from step 3 on the end:

If the link opens in Safari instead of Tracker, delete step 5 and add Show Notification ("Time to check in") instead. Open Tracker from your Home Screen and tap Paste from Shortcut in the check-in. Safari keeps separate data from the Home Screen app, so a check-in started there won't save.
